# SAPUI5 / SAP Fiori Course Quick Summary

> Short revision notes for the four SAP Learning courses provided.\
> Each unit is intentionally summarized in a few lines rather than

# 1. Advanced SAPUI5 Development

**Course:** [Advanced SAPUI5
Development](https://learning.sap.com/courses/advanced-sapui5-development)

**Level:** Intermediate · **6 Units** · **8h 42min**

## Unit 1 --- Implementing Full-screen Application

[Open course / Unit
1](https://learning.sap.com/courses/advanced-sapui5-development)

-   Build a full-screen SAPUI5 application.
-   Configure routing and navigation.
-   Work with local data and responsive layouts.
-   **Key takeaway:** Build and navigate a complete single-page UI5
    application.

## Unit 2 --- Implementing List-Detail Application

[Open course / Unit
2](https://learning.sap.com/courses/advanced-sapui5-development)

-   Build list-detail applications.
-   Work with root, list and detail views.
-   Configure routing and view synchronization.
-   Use `FlexibleColumnLayout` for responsive behavior.
-   **Key takeaway:** Build master-detail/list-detail UI5 applications.

## Unit 3 --- Working with UI5 Controls

[Open course / Unit
3](https://learning.sap.com/courses/advanced-sapui5-development)

-   Extend standard controls.
-   Create custom controls.
-   Create control/component libraries.
-   **Key takeaway:** Extend UI5 when standard controls are not
    sufficient.

## Unit 4 --- Using Metadata to Implement UI5 Controls

[Open course / Unit
4](https://learning.sap.com/courses/advanced-sapui5-development)

-   Understand metadata-driven controls.
-   Learn Smart Controls.
-   Introduction to the Flexible Programming Model.
-   **Key takeaway:** Metadata can drive UI behavior and reduce custom
    UI code.

## Unit 5 --- Ensuring Software Quality in UI5

[Open course / Unit
5](https://learning.sap.com/courses/advanced-sapui5-development)

-   Learn unit testing with QUnit.
-   Learn integration testing with OPA5.
-   **Key takeaway:** Test UI5 applications systematically instead of
    relying only on manual testing.

## Unit 6 --- Version Control --- Working in Teams

[Open course / Unit
6](https://learning.sap.com/courses/advanced-sapui5-development)

-   Use Git for source control.
-   Work with branches.
-   Understand team-based development.
-   **Key takeaway:** Manage UI5 source code safely in collaborative
    projects.

# 4. UI Development with SAP Fiori

**Course:** [UI Development with SAP
Fiori](https://learning.sap.com/courses/ui-development-with-sap-fiori)

**Level:** Advanced · **5 Units** · **1h 50min**

## Unit 1 --- Applying the Golden Rules of SAPUI5 Development

[Open course / Unit
1](https://learning.sap.com/courses/ui-development-with-sap-fiori)

-   Learn SAPUI5/Fiori development best practices.
-   Understand OData, metadata, app descriptors and platform
    independence.
-   **Key takeaway:** Follow SAP's development rules instead of creating
    custom solutions unnecessarily.

## Unit 2 --- SAP Fiori Launchpad

[Open course / Unit
2](https://learning.sap.com/courses/ui-development-with-sap-fiori)

-   Understand how applications are provided through the Fiori
    Launchpad.
-   Learn Launchpad-related concepts.
-   **Key takeaway:** Fiori applications are designed to run within the
    Launchpad environment.

## Unit 3 --- SAP Fiori Launchpad Configuration

[Open course / Unit
3](https://learning.sap.com/courses/ui-development-with-sap-fiori)

-   Learn Launchpad configuration.
-   Understand how applications are made available to users.
-   **Key takeaway:** Configuration connects applications, navigation
    and user roles.

## Unit 4 --- Applying SAP Fiori Design Guidelines

[Open course / Unit
4](https://learning.sap.com/courses/ui-development-with-sap-fiori)

-   Apply SAP Fiori design guidelines.
-   **Key takeaway:** UI should follow SAP's established design patterns
    and UX principles.

## Unit 5 --- Utilizing SAPUI5 Flexibility

[Open course / Unit
5](https://learning.sap.com/courses/ui-development-with-sap-fiori)

-   Learn SAPUI5 flexibility.
-   Adapt and extend existing Fiori applications.
-   **Key takeaway:** Flexibility allows UI adaptations while keeping
    the standard application maintainable.

# Recommended Learning Order

``` text
Developing UIs with SAPUI5
        ↓
Advanced SAPUI5 Development
        ↓
UI Development with SAP Fiori
        ↓
Fiori Elements + RAP
        ↓
Fiori Elements + CAP
```

For the Fiori Elements courses, the important relationship is:

``` text
RAP                              CAP
 │                                │
 ↓                                ↓
OData V4 Service              OData V4 Service
 │                                │
 └──────────────┬─────────────────┘
                ↓
        SAP Fiori Elements
                ↓
      List Report / Object Page
                ↓
        Fiori Launchpad
```

**Official SAP sources:** The unit names, durations, prerequisites and
course objectives above are based on the current SAP Learning course
pages. The CAP course currently has 14 units, the RAP course 11 units,
Advanced SAPUI5 has 6 units, and UI Development with SAP Fiori has 5
units.
