# ZPB_R_MT_VENDOR_DATA_M

**Helper CDS definition:** 8

```abap
define view entity ZPB_R_MT_VENDOR_DATA_M
  as select from ZPB_R_MT_ACC_DATA as a
    inner join   lfb1              as b on b.bukrs   = a.Bukrs
                                        and(
                                          b.lifnr    = a.lifnr
                                          or b.lifnr = a.gst_part
                                        )
{
  key a.Bukrs,
  key a.Belnr,
  key a.Gjahr,

      b.lifnr as VENDOR,
      b.mindk as MINDK

}
where
  a.koart = 'K'
```
